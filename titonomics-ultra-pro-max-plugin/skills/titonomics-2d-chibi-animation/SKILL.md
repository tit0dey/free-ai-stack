# TITONOMICS 2D / Chibi Animation

Animate the original mascot. Never redesign it.

## Preservation (absolute)
- Face, proportions, hairstyle, clothing, colours, identity unchanged. No AI distortion, no morphing, no different character.
- Use the supplied image only. Controlled compositing + subtle animation.

## Performance vocabulary
- Investigator: examining documents, pointing to evidence, inspecting a detail.
- Reactor: subtle head-turn, blink, bob, expression shift on revelation.
- Guide: standing beside a chart, bridging a transition, presenting a number.
- Movement: parallax, depth separation, squash-stretch (very subtle), slide-in/out.

## Rules
- ~10% screen time. Varied placement (left/right/centre, foreground/background). Never permanent bottom-corner. Never over captions/evidence.
- Chibi style only if it matches the original design language. If unsure, keep the original proportions.
- No lip-sync (narration is voiceover). No dancing, no meme gestures, no distracting loops.

## Output
Mascot cue sheet: timecode, pose/action, position, scale, duration, transition in/out. Every appearance must support the story beat.
