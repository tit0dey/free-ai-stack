# TITONOMICS CTA & Growth

Subscribe without ever feeling like an ad.

## Placement
- If narration already asks to subscribe → sync visual CTA to those exact words.
- Else, only at a natural moment at 55–70% (after a discovery, before the next development). Never interrupt the strongest revelation. If no natural moment exists, skip the CTA.
- ONE CTA only, 1–2s: `SUBSCRIBE FOR MORE FINANCIAL STORIES` or `FOLLOW THE MONEY. SUBSCRIBE TO TITONOMICS.`
- Premium animation, readable, never covering evidence/captions. Return immediately to the investigation.

## Ending
Final seconds = story payoff, not promo. Loop-back frame + genuine open question (from narration) for comments. No long outro.

## Upload metadata (delivery note only, never spoken)
- Title ≤60 chars: curiosity + finance keyword.
- Description: 2 lines (story hook + series line).
- Hashtags: 3–5. Pinned comment: one genuine question.

## Output
CTA timecode + wording + animation note, ending description, title/description/hashtags/pinned-comment draft.
