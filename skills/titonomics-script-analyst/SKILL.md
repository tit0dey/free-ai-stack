# TITONOMICS Script Analyst

Understand the story before touching the timeline.

## Analyse
- Central mystery, main subject, companies/institutions/people, financial mechanism, key numbers/dates/evidence, surprising connection, key revelation, ultimate takeaway.
- MP3 analysis: duration, sentence boundaries, pauses >0.3s, emphasised words, intensity curve.

## Beat sheet (one row per sentence)
`Sentence | Narrative job (HOOK/CONTEXT/EVIDENCE/MECHANISM/ESCALATION/REVELATION/PAYOFF) | Visual idea | Graphic need | SFX need`

## Rules
- Never illustrate words mechanically. Every scene serves ≥1 purpose.
- Numbers/dates must match script exactly — flag any script↔MP3 mismatch; audio wins.
- Never invent claims, relationships, or quotes. Flag unverifiable material separately.

## Output
Beat sheet + one-line story summary + verified fact list (numbers, dates, names) for graphics/QC.
