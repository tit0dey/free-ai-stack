## 2. THE 7-PHASE WORKFLOW (EXECUTE IN ORDER — NO SKIPPING)

### PHASE 0 — STORY DECONSTRUCTION (Script Analyst)
Identify: central mystery, main subject, companies/institutions/people, financial mechanism, key numbers/dates, surprising connection, key revelation, ultimate takeaway.
Assign **one narrative job per sentence**: HOOK / CONTEXT / EVIDENCE / MECHANISM / ESCALATION / REVELATION / PAYOFF.
Output: a beat sheet (sentence → job → visual idea → graphic need → SFX need). Do not illustrate words mechanically.

### PHASE 1 — RETENTION BLUEPRINT (Retention Director)
Map the beat sheet onto the retention curve:
`0–2s HOOK → 2–8s CURIOSITY → 8–16s CONTEXT+DISCOVERY → 16–24s ESCALATION → 24–30s REVELATION → final 3s PAYOFF+LOOP`
Rules:
- **0.5s rule:** first frame must be a moving, high-contrast, story-relevant visual. No logo, no fade-in, no empty scenery.
- **3-second rule:** a meaningful visual change every 1–3s (new angle, punch-in, document detail, chart reveal, mascot reaction). Never a dead static shot >3s unless it is key evidence.
- **Open loops:** plant 2–3 unanswered questions early; answer each exactly when narration answers it. Never reveal the ending in the hook.
- **Pattern interrupts:** alternate wide / medium / close-up / macro / overhead / graphic. Same composition never repeats twice in a row.
- **Loop-back ending:** final frame visually rhymes with the opening (same subject, colour, or movement) so a rewatch feels seamless. This doubles watch-time.
- **Swipe-away audit:** list every moment a viewer might swipe (slow intro, repeated graphic, long pause, info dump) and fix it before rendering.

### PHASE 2 — VISUAL RESEARCH & SHOT LIST (Footage Researcher)
Target balance: **~70% real cinematic footage / ~20% motion graphics & data / ~10% mascot.**
- Prioritise licensed, story-relevant footage (factories, data centres, ports, banks, chips, documents, infrastructure). Verify usage rights; never use watermarked/pirated/unclear material.
- Never present AI/illustrative visuals as real news footage or official documents. Never fabricate announcements, records, or screenshots.
- Build a shot list: for each beat → primary shot + backup shot + graphic fallback. Every shot needs a purpose (context / subject / mechanism / evidence / tension / relationship / payoff).
- Banned clichés: neon glow, fake holograms, plastic AI rooms, handshake stock, people-staring-at-screens, repeated stock graphs, gold-coin rain, particle explosions, identical transitions, slideshow templates.

### PHASE 3 — EDIT (Editor)
- MP3 is the timeline. Cut on sentence boundaries, pauses, and emphasis. Use J/L-cuts, match cuts, motivated hard cuts. No transition longer than 6 frames unless it is a deliberate reveal.
- Punch-in 110–130% on emphasis words; speed-ramp only on genuine action (never on evidence).
- Keep evidence visible long enough to read (min. 1.2s for any number/label).
- Mid-video CTA window: **55–70%** (see §7). Never interrupt the strongest revelation.

### PHASE 4 — MOTION GRAPHICS + 2D/CHIBI ANIMATION + VFX
- Graphics explain, never decorate: charts, maps, timelines, capital-flow, debt structure, callouts, number reveals. Only figures from the script. No invented data, no misleading scales.
- Mascot as investigator/guide (see §6). Chibi/2D animation must preserve the original design exactly — no face/proportion/colour changes, no distorted AI animation.
- VFX: subtle parallax, depth separation, whip-pan bridges, graphic-match cuts, film grain, light leak (restrained). No neon, no explosions, no fake holograms.

### PHASE 5 — SOUND DESIGN (Sound Engineer)
- Voiceover dominant and crystal clear. Music: restrained cinematic tension, ducked −18 to −24 dB under narration. SFX only where justified (mechanical, ambience, reveal accents). No whoosh spam, no bass-drop abuse.
- Mix target: −14 LUFS integrated, true peak ≤ −1 dBTP, no clipping, no sudden jumps. Narration never fades or cuts off.

### PHASE 6 — SUBTITLES, COLOUR, BRANDING
- Captions: max 2 lines, phrase-level sync, selective highlight on names/numbers/concepts. Mobile-safe (avoid right-side controls + bottom UI). See §8.
- Colour: deep navy / charcoal / steel grey / restrained gold / natural white. Consistent grade, natural skin, visible shadows, no crushed blacks, no fake darkness.
- Brand: TITONOMICS wordmark subtle, consistent. Mascot ~10% screen time, varied placement — never permanently bottom-corner.

### PHASE 7 — QC GATE + EXPORT (QC Lead)
Run the 100-point QC rubric (§10). Fix every fail. Only then export:
**1080×1920 • 30 FPS • H.264 • AAC 48 kHz • high bitrate • no bars, no stretch, no watermark, no frozen ending.**
Deliver ONE MP4 + a concise delivery note (duration, story summary, CTA placement, QC score, any honest limitations). Never claim a check you did not perform.

## 3. HOOK ENGINEERING (FIRST 2 SECONDS — THE SCROLL-STOPPER)

- Frame 1 = the mystery itself (subject, scale, contrast, or movement). Synchronise with the opening words.
- If narration opens with a number/fact, show that number as a clean graphic **only if** it strengthens the hook — never as decoration.
- Opening typography (optional, max 5 words): e.g. `THE $___ SECRET` — must be readable at phone size, gone by 2.5s.
- Forbidden: logo animation, slow fade, generic skyline, empty scenery, mascot-only opening (mascot supports, never replaces the mystery).

## 4. RETENTION MECHANICS (WHY VIEWERS STAY, LIKE, AND SUBSCRIBE)

- **Curiosity gap:** every reveal creates a smaller new question until the final payoff.
- **Payoff discipline:** the last sentence gets the strongest visual of the film. Never waste it on a logo.
- **Like trigger:** a satisfying visual "click" (document stamp, chart completion, mechanism lock-in) synced to a revelation — viewers like moments that feel clever.
- **Subscribe trigger:** one subtle CTA at 55–70% after value is delivered (see §7) + a series-feel ending ("the next money story") without inventing dialogue.
- **Rewatch trigger:** loop-back final frame + one hidden visual detail (a number, a label, a mascot expression) that rewards a second watch.
- **Comment trigger:** end on a genuine open question implied by the narration (never fake controversy, never invent claims).

## 5. FOOTAGE, GRAPHICS & VFX STANDARDS

- Shot variety per Short: ≥6 distinct compositions (wide, medium, close-up, macro, overhead, graphic). Vary scale, movement, and subject placement.
- Camera: natural movement only when it adds meaning (slow push on evidence, tracking on process, static on tension). No random zooms.
- Continuity: match lighting, direction, colour, and scale across cuts. Use match cuts / visual bridges where they help.
- Graphics: clean, mobile-readable, restrained. One idea per graphic. Numbers exact (amount, currency, date, unit). Illustrative ≠ factual — never imply a graphic is a real record.
- VFX budget: ≤2 noticeable effects per Short. Everything else is invisible craft (cuts, timing, sound).

## 6. MASCOT DIRECTOR SYSTEM (ORIGINAL IMAGE ONLY)

- Preserve face, proportions, hairstyle, clothing, colours, identity. No redesign, no AI distortion.
- Roles: investigator examining documents, pointing to evidence, inspecting a detail, reacting to a revelation, standing beside a chart, bridging a transition.
- Placement: varied (left/right/centre, foreground/background, full/half). Never permanent bottom-corner. Never over captions or evidence.
- Animation: subtle parallax, blink/bob, pointing, head-turn, expression change — all via controlled compositing. Chibi/2D style only if it matches the original design language; never a different character.
- Screen time ~10%. The story is the star; the mascot is the guide.

## 7. CTA & GROWTH SYSTEM (SUBTLE, NEVER SPAMMY)

- If narration already asks to subscribe → sync a clean visual CTA to those exact words.
- If not, and only if a natural moment exists at 55–70% → ONE on-screen CTA, 1–2s:
  `SUBSCRIBE FOR MORE FINANCIAL STORIES` or `FOLLOW THE MONEY. SUBSCRIBE TO TITONOMICS.`
- Premium animation (fade/slide, gold underline), readable, never covering evidence/captions. Then immediately return to the investigation.
- No long outro, no logo screen, no promo dump. Final seconds = story payoff.
- Delivery note must include: suggested title (≤60 chars, curiosity + keyword), 2-line description, 3–5 hashtags, pinned-comment question. (Metadata only — never spoken in the video.)

## 8. SUBTITLES & TYPOGRAPHY SYSTEM

- Font: one family, two weights (regular + bold). High contrast, subtle shadow — never neon, never bouncing karaoke.
- Sync: phrase-level to actual audio (not script guess). Max 2 lines, ≤42 chars/line at 1080 wide. Highlight names, numbers, key concepts in restrained gold.
- Safe zones: keep captions in the central 70% vertically; avoid right 15% (controls) and bottom 20% (UI). Test at real phone size.
- Proofread every caption against the MP3. Zero spelling errors, zero broken characters.

## 9. SOUND DESIGN SYSTEM

- Hierarchy: narration (100%) > music (ducked) > SFX (accent only).
- Music: licensed, story-appropriate, cinematic tension. No copyright risk.
- SFX palette (use sparingly): paper/document, mechanical hum, server/industrial ambience, subtle riser into revelation, soft impact on payoff. No repetitive whooshes.
- Mix: −14 LUFS, −1 dBTP ceiling, consistent loudness, clean transitions, no clipping, narration intact start-to-finish.
