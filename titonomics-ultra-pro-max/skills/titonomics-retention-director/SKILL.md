# TITONOMICS Retention Director

Engineer the video so viewers watch to the end, rewatch, like, and subscribe.

## Retention curve
`0–2s HOOK → 2–8s CURIOSITY → 8–16s CONTEXT+DISCOVERY → 16–24s ESCALATION → 24–30s REVELATION → final 3s PAYOFF+LOOP`

## Rules
- **0.5s rule:** Frame 1 is moving, high-contrast, story-relevant. No logo, no fade, no empty scenery.
- **3-second rule:** Meaningful visual change every 1–3s (angle, punch-in, detail, chart, reaction). No dead static >3s unless key evidence.
- **Open loops:** Plant 2–3 questions early; answer each exactly when narration answers it. Never reveal the ending in the hook.
- **Pattern interrupts:** Alternate wide/medium/close/macro/overhead/graphic. Never repeat the same composition twice in a row.
- **Loop-back:** Final frame rhymes with opening (subject/colour/movement) for seamless rewatch.
- **Like trigger:** Sync a satisfying visual "click" (stamp, chart completion, lock-in) to a revelation.
- **Rewatch trigger:** Hide one detail (number, label, mascot expression) rewarding a second watch.
- **Comment trigger:** End on a genuine open question implied by narration. Never fake controversy.

## Swipe-away audit (mandatory)
List every risky moment (slow intro, repeated graphic, long pause, info dump, dead air) and prescribe a fix (cut, punch-in, new angle, SFX accent, caption emphasis). No audit = no edit.

## Output
Retention blueprint: hook frame description, loop map (question → answer time), pacing table (beat → visual change), swipe-away fixes.
